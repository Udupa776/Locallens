# LocalLens 🌍  
*A Hyperlocal Civic Issue Reporting Platform*

## 📌 Project Overview
**LocalLens** is a hyperlocal, web-based civic engagement platform designed to bridge the communication gap between citizens and local authorities. The platform enables users to report, view, and track local civic issues such as potholes, garbage dumps, water leaks, and stray animals, fostering transparency and community participation.

This project is developed as part of **Mini Project ** for the course **Object Oriented Programming with Java **.

---

## 🚀 Key Features
- 📸 **Issue Reporting** with image upload, description, category, and location tagging   
- 💬 **Comments & Feedback System** for public transparency  
- 🤝 **Email Verification** with sendgrid   

---

## 🛠️ Technology Stack (Proposed)
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Java (Object-Oriented Design)  
- **Database:** PostgreSQL (Supabase)  

---

## 🔧 Feature Enhancements (Future Scope)
- 🗺️ **Map-Based Visualization** of nearby issues and solutions  
- 🔄 **Real-Time Status Tracking** of reported issues
